# MOTI (모티) 개인정보 처리방침

## 1. 처리하는 개인정보

• 계정: 이름(닉네임), 이메일 주소. Apple 로그인을 쓰면 Apple이 알려 주는 이름, 이메일(가린 주소일 수 있음), 계정 식별값  
• 학습 자료: 플랜, 공부 시간, 단어장, 오답노트(문제 사진, 필기, 답), 메모, AI와 나눈 대화, 모의고사 기록, 받은 배지  
• 랭킹에 참여한 경우: Game Center 닉네임과 공부 시간  
학습 자료는 이 기기 안에 저장되고, iCloud 동기화를 켜면 본인의 iCloud에도 저장돼요. 운영자는 서버를 두지 않으며 이 정보를 모으지 않아요.

## 2. 처리 목적

로그인과 계정 구분, 학습 기록 저장과 통계, 오답노트·AI 풀이, 랭킹 표시를 위해서만 써요.  
광고, 마케팅, 판매에는 쓰지 않아요.

## 3. 보관 기간과 파기

이용자가 앱에서 지우거나 [계정 삭제]를 하거나 앱을 지울 때까지 기기에 보관돼요.  
계정을 삭제하면 기기 안의 계정 정보와 학습 자료를 바로 지우고, iCloud 동기화를 켰다면 iCloud의 자료도 지워요.  
iCloud에 남은 자료는 iPhone 설정 → Apple 계정 → iCloud → 저장 공간 관리에서도 지울 수 있어요.

## 4. 밖으로 보내는 정보 (외부 서비스)

앱은 아래 경우에만 기기 밖으로 정보를 보내요.  
• Apple iCloud (iCloud 동기화를 켰을 때만): 학습 자료를 본인 iCloud 계정에 암호화해 저장하고 같은 Apple ID 기기끼리 이어 줘요. 운영자는 볼 수 없어요.  
• Apple (로그인, Game Center 랭킹): 로그인 정보, 랭킹에 참여하면 공부 시간  
• DuckDuckGo (모티 AI 인터넷 검색, 켰을 때만): 검색어  
• Free Dictionary API (영어 단어 뜻 찾기): 찾는 영어 단어  
• Hugging Face (AI 모델 받기): 개인정보를 보내지 않아요  
AI 풀이, 사진 인식(정밀 인식 포함), 모티 1·2 대화는 기기 안에서 처리되어 문제 사진과 대화 내용을 밖으로 보내지 않아요.  
발음 연습과 모티 AI에 말로 질문하기의 음성 인식은 기기 안에서 하며, 기기가 지원하지 않으면 Apple의 음성 인식을 거칠 수 있어요. 녹음한 소리는 저장하지 않아요.

## 5. 기기 권한

• 카메라 · 사진: 단어장·문제 사진 찍기와 불러오기  
• 마이크 · 음성 인식: 영어 발음 연습, 모티 AI에 말로 질문하기  
• 알림: 플랜 알림  
• 스크린 타임: 공부 중 다른 앱 잠금 (쓸 때만)  
모두 선택이며, 허용하지 않아도 다른 기능은 쓸 수 있어요. iPhone 설정에서 언제든 바꿀 수 있어요.
