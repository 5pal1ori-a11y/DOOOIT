# MOTI UI 방향 (ui-redesign)

목표: "AI가 만든 앱" 같은 느낌을 빼고, 토스·애플 건강/시계·Things 같은 "원래 있던 앱"처럼 보이게 한다.
기능·데이터·테마(4종 3색)·Pretendard·효과음·다크 모드는 그대로 둔다.

## 조사 요약

조사 환경에서 일부 사이트(토스·듀오링고 블로그 등)는 접속이 막혀 검색 결과와 공개 요약, 널리 알려진 앱 구조를 근거로 정리했다.
브랜드 그림·글꼴·문구는 베끼지 않고 원리만 가져온다.

| 앱 | 가져올 원리 |
| --- | --- |
| 토스 (만보기 랭킹 포함) | 화면마다 숫자 하나가 가장 크다. 해요체, 일상어, 짧은 문장. 글머리 아이콘 없이 글자와 숫자 중심. 강조색은 파랑 하나. |
| 듀오링고 리그 | 순위 목록 한 줄 = 순위 · 이름 · 점수. 내 줄만 바탕색으로 구분. 승급 구간은 선 하나로 나눔. 주 단위로 초기화. |
| 애플 피트니스 · 건강 | 큰 숫자 + 작은 단위, 그 아래 얕은 회색 설명. 카드는 평평한 회색/흰색, 그림자 없음. 링은 한 가지 색. |
| 애플 시계 · 설정 | 목록은 묶음(inset grouped) + 머리글선(hairline). 아이콘은 작게, 줄 높이 44~52. |
| Things 3 | 카드보다 종이 같은 목록. 여백과 글자 크기 차이로 위계를 만들고 색은 의미(오늘·마감)에만 쓴다. |
| Strava · Forest | 순위 표는 표처럼 정렬(순위 열, 이름, 기록 열 오른쪽 정렬). 친구/내 기록을 먼저, 장식은 최소. |
| 노션 캘린더 · Streaks | 밀도 높은 정보, 얇은 선, 단색 아이콘, 강조색은 오늘/선택 표시에만. |
| 네이버 · 카카오 | 숫자와 라벨을 같은 줄에 나란히, 목록은 구분선으로 나눔, 모서리는 8~12pt 정도로 작다. |

"AI 느낌"으로 꼽히는 것 (블로그·디자인 글 공통): 보라/파랑 그라데이션과 빛 번짐, 유리 카드, 반짝이(sparkles) 아이콘과 AI 배지,
모든 줄의 아이콘이 색 있는 둥근 네모 안에 들어 있는 것, 모든 것에 큰 모서리와 부드러운 그림자, 가운데 정렬 큰 제목, 이모지, 좌우 대칭 카드 격자, 과한 심볼 애니메이션.

## 규칙

### 색
1. 강조색은 한 가지(`Theme.accent`). 버튼 · 선택 · 링 · 그래프의 "지금" · 내 줄에만 쓴다.
2. 아이콘은 단색(본문 회색/글자색). 줄마다 다른 파스텔 색 금지. 빨강은 삭제/경고에만.
3. 바탕은 단색 (`Theme.base`: 밝게 #F5F6F8 · 어둡게 #000). 빛 번짐·그라데이션 바탕 없음.
4. 3색 그라데이션(`Theme.current.fill`)은 "가장 중요한 버튼 하나"에만. 그 외 채움은 단색.
5. 의미 색(성공 초록, 위험 빨강)은 글자·점 하나로만 쓰고 넓은 면에 칠하지 않는다.

### 면과 선
6. 카드는 단색 면(`Palette.card`) + 0.5pt 헤어라인 테두리. 그림자 없음. 유리(glassEffect)는 시스템이 주는 탭 바·하단 바에만.
7. 모서리 반지름은 한 종류: 카드 14, 작은 칸 10, 버튼 14, 칩 6. 큰 둥근 카드(26+) 금지.
8. 목록 줄 사이는 구분선(헤어라인), 카드 사이는 12~16 간격. 카드 안에 또 카드 쌓기 금지.
9. 간격은 4/8/12/16/24만. 화면 좌우 여백 16 (기존 20에서 줄임).

### 글자와 숫자
10. 숫자는 항상 `monospacedDigit` (시간·순위·점수). 화면의 핵심 숫자 하나는 32~40pt bold, 단위는 같은 줄 15pt regular 회색.
11. 글자 크기 단계: 34(큰 제목) · 28 · 20(구역 제목) · 17(본문) · 15(보조) · 13(설명) · 11(작은 글). 굵기는 regular/semibold/bold 셋만.
12. 왼쪽 정렬. 가운데 정렬은 빈 상태와 타이머에만.
13. 구역 제목은 한 줄 글자(20 semibold)이고 아이콘 없음. 오른쪽에 작은 텍스트 버튼.

### 글과 상태
14. 한국어 해요체, 한 줄 안쪽. 설명 문장 대신 숫자와 라벨. "~할 수 있어요" 안내는 꼭 필요한 곳 하나만.
15. 이모지·"AI" 배지·반짝이 아이콘 금지(모델 이름은 글자로). 모티 AI 탭 아이콘도 말풍선.
16. 빈 상태: 단색 아이콘(회색) + 한 줄 + 필요하면 글자 버튼. 색 있는 큰 네모 금지.
17. 애니메이션은 화면 전환·숫자 바뀜·누름(투명도 0.7)만. 바운스/펄스/글로우 없음. 등장 애니메이션은 6pt 이동 + 페이드.

### 부품 (공용 컴포넌트가 이 규칙을 대신 지킨다)
- `softCard` / `softCardBackground`: 단색 + 헤어라인, 반지름 14.
- `RowLabel`: 단색 22pt 아이콘, 파스텔 칸 없음. `RowDivider`: 헤어라인.
- `SectionTitle`/`SectionHeader`: 글자만. `EmptyStateView`/`IconBadge`/`TagLabel`: 평평하고 작게.
- `PrimaryButtonStyle`: 높이 52, 반지름 14, 그림자 없음, 누르면 투명도만.
- `PillSegmentedControl`: 시스템 분할 선택기처럼 회색 바탕 위에 흰 칸.
- `AppBackground`: 단색. `BrandBackdrop`: 아주 옅은 위쪽 색조 하나.

## 랭킹 화면

- 위: 기간 분할 선택기(일간 · 주간 · 월간) → 날짜 이동 줄(작게).
- "내 순위" 요약: 큰 순위 숫자("12등") + "상위 8%" + 내 시간. 카드 하나, 가운데 정렬 없음.
- 목록: 순위 열(고정 폭, 오른쪽 정렬 숫자) · 이름 · 시간(오른쪽, 큰 숫자 가운데 tabular).
  1~3위는 메달/왕관 없이 순위 숫자만 강조색 + bold. 내 줄은 연한 강조색 바탕, 그리고 화면 아래에 고정(내가 목록 밖이면).
- 줄 사이 헤어라인, 막대 그래프는 1위 대비 얇은 1pt 줄 하나로 줄이거나 뺀다(시간 숫자가 주인공).
- 로그인/참여 안내는 한 문장 + 버튼 하나. Game Center 로그인·참여·게스트 잠금 로직은 그대로.

## 하지 않는 것
- 새 색 추가, 새 글꼴, 새 이미지 자산.
- 데이터 모델·저장소 이름 변경.
- OCR/필기 필터/AI 엔진 코드.
