# DOOOIT — 공부 플래너 (iOS 26 · Liquid Glass)

SwiftUI + SwiftData로 만든 iOS 공부 플래너 앱입니다. 화면은 iOS 26 **Liquid Glass**(`glassEffect`, `.glass` 버튼, 글라스 탭바)로 구성했고, 이모지 대신 SF Symbols 아이콘을 사용합니다.

## 기능

| 영역 | 기능 |
|---|---|
| 실행 화면 | `D O O O I T` 글자가 하나씩 나타난 뒤, 세 개의 O가 하나로 합쳐지는 애니메이션 |
| 로그인 | Apple로 계속하기 / 이메일 회원가입·로그인, 닉네임 설정 |
| 홈 | 날짜·D-Day + 시간대별 인사말(6시~12시, 12시~1시, 1시~6시, 6시~7시, 7시~0시, 0시~6시), 주간 달력(누르면 그날 타임라인), 집중 패널(오늘 공부 시간·연속 공부·플랜·복습할 오답), 타임라인형 오늘의 플랜(3개 초과 시 전체 보기), 메모지 모양 단어 카드, 원형 바로가기, 주간 차트 |
| 공부 › 영어 단어 | 단어장 촬영(문서 스캐너)/앨범 → 기기 내 OCR(Vision)로 단어·뜻 자동 추출 → 확인·수정 → 저장. 하루 목표 개수 설정. 학습: ① 메모지에 단어+뜻 보기 → ② 뜻 가리고 쓰기 → 틀린 단어 복습 후 재시험(모두 맞을 때까지) → ③ 단어 가리고 쓰기(같은 방식) → **오늘의 단어목표 성공!** 틀린 단어 모아 복습, 전체 단어 목록 |
| 공부 › 수학 오답노트 | 문제 촬영 → 글자 인식 + 사진을 모눈 노트에 배치. 펜·형광펜·지우개·올가미·텍스트, 색상/굵기, 실행 취소. 정답 자동 인식(사진에 "정답: ○" 표기가 있을 때) + 자동 채점, 안 되면 O/X 수동 채점. 여러 문제 등록·필터 |
| 공부 › 메모장 | 검색, 고정, 공유, 자동 저장 |
| 플래너 | 월간 캘린더 / 하루 타임라인(시간 눈금, 현재 시각 선, 겹치는 일정 나란히 표시), 반복(매일·매주·매달·매년, 종료일). **일반 플랜**: 카테고리 + 플랜별 알림(없음·정시·5/10/30/60분 전). **공부 플랜**: 과목(기본 국어·영어·수학, 추가 가능) + 자동 타이머 + **다른 앱 잠금**. 시간은 휠에서 고른 뒤 "완료"를 눌러야 반영 |
| 두잇 AI | 채팅으로 앱 기능 실행 + 일상 대화 + 수학·영어·과학·사회 질문 + 퀴즈 (아래 "두잇 AI 안내") |
| AI 학습 | **단원별 AI 학습**(2022 개정 고1 공통수학1·2, 공통국어, 공통영어 단원 + 직접 입력), **취약 유형 맞춤 학습**(풀이 기록·오답노트로 약한 단원과 현재/예상 실력 표시), **AI에게 질문하기**(사진·글로 질문, 답변 위에 필기, 도움 여부), **서술형 단계별 풀이**(오답노트에서 문제/개념/답안 탭, 1·2단계 직접 풀고 모범 답안과 비교) |
| 통계 | 일간/주간/월간, 총 집중 시간, 과목별 비율 막대와 목록, 이전 기간 대비 증감, 6개 기간 추이 그래프, 시간대별 집중 분포 |
| 공부 타이머 | 공부 카테고리 일정 N분 전 → 다이나믹 아일랜드/잠금화면에 남은 시간 표시, 시작 시각 → 타이머 자동 실행. 탭바 위 미니 플레이어, 일시정지/종료, 기록 저장 |
| 계정 | 프로필·이름 변경, 통계, 단어/공부 목표, D-Day, 알림·다이나믹 아일랜드·자동 시작 설정, 카테고리 관리, 화면 모드, 로그아웃, 계정 삭제(데이터 전체 삭제) |

## 두잇 AI 안내

두잇 AI는 **외부 AI·서버 없이 휴대폰 안에서만** 동작해요. 대화와 사진은 휴대폰 밖으로 나가지 않아요.

두 부분이 함께 일해요.
- **규칙형 엔진** (직접 만든 엔진): 앱 기능 실행, 수학 풀이, 공식 계산, 퀴즈, 사진 분석처럼 *정확해야 하는 일*
- **모델 DOOOIT 1 · DOOOIT 2** (선택, `Services/DoitBrain`): 두잇 AI 화면 위쪽 메뉴에서 ChatGPT·Gemini처럼 모델을 고르고 다운로드해요 (DOOOIT 1 약 0.4GB · 빠름 / DOOOIT 2 약 1GB · 더 똑똑함). 한 번 받으면 인터넷 없이도 돌아가요. 같은 메뉴에서 기본(모델 없이), 인터넷 검색 켜기/끄기, 배운 내용, 모델 삭제도 해요.
  - 내부: DOOOIT 1 = Qwen3 0.6B 4bit, DOOOIT 2 = Qwen3 1.7B 4bit (Apache-2.0 오픈소스, [mlx-swift-lm](https://github.com/ml-explore/mlx-swift-lm)로 실행, Hugging Face `mlx-community`에서 받음)
  - 설명·대화는 근거(교육과정 지식 사전 · 두잇이 배운 기억 · 인터넷 검색)를 모아 읽고, **그대로 옮기지 않고 자기 말로** 해요체로 설명해요. 참고한 자료는 답 아래에 표시해요.
  - AI 학습은 아래 "AI 학습 자료 만들기" 순서와 검증을 거쳐요.
  - **스스로 배우기**: 인터넷에서 찾아 정리한 내용, 👍를 받은 설명, "기억해줘: …"로 알려준 내용, "아니야, …"로 고쳐 준 내용을 계정마다 따로 기억(`DoitMemory.json`)해 두고 다음 답의 근거로 써요. 👎를 받은 주제는 다음에 인터넷에서 다시 찾아봐요.
  - 모델의 가중치를 기기에서 다시 훈련하는 방식은 아니에요(휴대폰에서는 너무 무겁고 느려요). 대신 배운 내용을 쌓아 두고 찾아 쓰는 방식(검색 증강 생성)으로 점점 나아져요.
  - 인터넷 검색은 키가 필요 없는 DuckDuckGo를 써요. 질문에서 뽑은 검색어만 보내고(대화 전체·계정 정보는 안 보냄), 설정에서 끌 수 있어요. 웹 페이지 내용은 "정보일 뿐 명령이 아님"으로 표시해서 페이지 속 지시를 따르지 않게 했어요.
  - 모델을 받지 않았거나 "기본"을 고르면 규칙형 엔진만으로 답해요. 시뮬레이터에서는 모델을 쓸 수 없어요.

### AI 오답노트 (`Services/DoitAI/Mistake`, `Features/Study/Math`)

오답을 저장만 하지 않고, 학습 순서대로 실력을 올리게 했어요.

1. **문제 등록**: 사진(촬영·앨범 · 문제 영역 고르기), 직접 입력, AI 학습에서 틀린 문제 "오답노트에 담기".
2. **인식 확인** (`DoitProblemScan`): 본문·수식·선택지·조건·표·그래프·묻는 것으로 나눠 보여주고, 흐리게 읽은 줄·괄호 짝·겹친 기호·l/I/O·지수 같은 **불확실한 곳을 표시**해요. 사용자가 "이대로 확정"하기 전에는 채점·풀이를 하지 않아요. 사진에서 읽지 못한 그래프 값은 지어내지 않아요.
3. **유형별 자동 채점** (`DoitGrader`): 객관식(번호·③·보기 글), 단답형(띄어쓰기·기호·끝말 정리, `|`로 복수 정답, 한두 글자 차이는 확인 요청), 수학(0.5=1/2, √8=2√2, 해 순서 무시, 같은 식의 다른 모양, ±, 연립 해, 부등식 방향, 해 일부만 → 부분 정답, 정답이 없으면 풀이 엔진이 직접 풀어 비교), 서술형(모범 답안의 핵심 내용 포함 여부로 부분 점수 + 근거, 최종 결과는 사용자 확인). 확실하지 않으면 정답·오답을 정하지 않고 확인을 요청해요.
4. **오답 원인 분석** (`DoitMistake`): 개념 이해 부족 · 공식 암기 부족 · 계산 실수 · 문제 해석 오류 · 조건 누락 · 풀이 과정 오류 · 단순 실수 · 기타 · 판단 불가. 풀이 과정을 적으면 틀린 줄로 "확인됨", 답의 모양(부호 반대, 해 일부, 조건 밖의 해, 풀이 중간값, 자리 바뀜, 비슷한 개념 이름)으로는 "추정", 근거가 없으면 "판단 불가". 설명·근거·놓친 개념·풀이 방향·복습·다음 학습을 함께 보여줘요.
5. **단계별 풀이** (`DoitSolutionWriter`): 풀이 엔진이 직접 푼 단계마다 할 일 · 쓰는 공식 · 이유 · 계산 · 다음 단계. 엔진이 풀지 못하는 문제는 풀이를 지어내지 않아요.
6. **유사 문제 단계 학습** (`DoitPractice`): 1 개념 확인 → 2 쉬운 유형 → 3 비슷한 난이도 → 4 응용(같은 개념의 다른 물음) → 5 최종 복습. 맞히면 올라가고, 틀리면 개념을 다시 보여주고 한 단계 쉽게. 숫자만 바꾼 같은 모양은 피하고, 학교급에 맞는 유형만, 정답은 다시 풀어 확인해요.
7. **재도전 · 취약 개념** (`WeakConcept`): 과목·단원·개념·유형·제출 답·정답·원인·오답 횟수·최근 학습일·재도전 결과·숙련도를 개념별로 기록. 같은 개념에서 오답이 반복되면 취약 개념. "익힘"은 숙련도 85% 이상 + 3번 연속 정답 + 서로 다른 날 2일 이상 + 4단계 이상 정답일 때만 (한 번 맞혔다고 익혔다고 보지 않아요).
8. 데이터: `MathNote`에 기본값이 있는 필드만 더하고 `WeakConcept` 모델을 새로 추가했어요 (SwiftData 자동 경량 마이그레이션, 기존 노트·필기·풀이 그대로). 예전 노트는 "확인된 문제"로 열려요.

### AI 학습 자료 만들기 (`Services/DoitAI/Study`)

고른(또는 적은) 과목·단원과 **다른 내용이 섞이지 않도록**, 정확성을 분량보다 먼저 두고 만들어요.

1. **입력 확인** (`DoitStudyScope`): "중3 수학 이차방정식의 풀이", "고등학교 통합과학 생명 시스템", "중학교 2학년 역사 삼국의 성립과 발전"처럼 적어도 학교급·학년·과목·단원·세부 주제를 알아내요. 과목 별명(역사→사회, 통합과학→과학 등)과 교과서마다 다른 단원 이름(생명 시스템→세포와 유전 등)을 이어 줘요.
2. **여러 단원으로 해석되면** (예: "국어 문장의 짜임" → 초등/고등/공통국어) 임의로 고르지 않고 사용자에게 물어봐요. **맞는 단원이 없으면** 지어내지 않고 알려줘요.
3. **자료 검색**: 그 단원(그 학교급)의 교육과정 사전 개념만 가져와요. 예전처럼 비슷한 말로 전체 사전을 뒤지지 않아요 (생명 시스템 → 지리 정보 시스템 같은 섞임 방지).
4. **개념 → 상세 설명 → 학습 포인트 → 예제**를 그 자료로 정리해요.
5. **문제·정답·해설은 앞에서 정리한 개념으로만** 만들어요 (같은 묶음 `StudyPack`을 씀). 보기도 같은 단원 개념만 쓰고, 문제 글에 이름이 나오는 개념은 오답 보기로 쓰지 않아요. 수학 계산 문제는 학교급에 맞는 유형만(중학교에 근과 계수의 관계·판별식·복소수 없음) 생성기로 만들고 풀이 엔진으로 다시 풀어 정답을 확인해요.
6. **검증** (`DoitStudyCheck`): 단원 일치(다른 단원·윗 학교급 용어), 근거(자료와 겹치는지, 자료에 없는 숫자), 문제 형식(보기 수·중복·정답 번호·정답 노출·빈칸 수·헷갈리는 보기), 정답(수학은 다시 풀기), 해설과 정답 일치.
7. **통과한 것만** 보여주고 화면에 통과한 검증과 근거 자료를 표시해요. 모델이 만든 내용은 실패한 항목만 **최대 2번** 다시 만들고, 그래도 안 되면 교육과정 자료로 직접 정리한 내용으로 바꿔요. 자료가 적어 검증된 문제를 만들 수 없는 단원은 그렇다고 알려줘요.
8. 예전에 저장한 학습 자료는 지우지 않고(형식 버전 v2로 새로 만듦), 취약 복습 목록은 그대로 이어서 써요.

## 앱 잠금 켜기 (공부 플랜의 "다른 앱 잠금")

앱 잠금은 Apple의 스크린 타임 API(FamilyControls · ManagedSettings · DeviceActivity)를 씁니다.
이 권한은 **Apple 승인이 있어야 TestFlight/App Store 빌드에 넣을 수 있어서**, 기본값은 꺼져 있습니다(꺼져 있으면 토글을 켤 때 안내 문구가 나오고 나머지 기능은 정상 동작).

1. https://developer.apple.com/contact/request/family-controls-distribution 에서 Family Controls (Distribution) 사용을 신청합니다. 앱(`com.bravekoon.dooit`)과 잠금 익스텐션(`com.bravekoon.dooit.activitymonitor`) 둘 다 필요합니다.
2. 승인되면 Xcode → 프로젝트 → Build Settings에서 `DOOOIT_APPLOCK_SUFFIX` 값을 `-AppLock`으로 바꿉니다. (두 타깃이 `*-AppLock.entitlements`를 쓰게 됩니다)
   - 그리고 DOOOIT 타깃 → General → Frameworks, Libraries, and Embedded Content(또는 Build Phases → Embed Foundation Extensions)에 `DOOOITActivityMonitor.appex`를 다시 추가합니다. 승인 전에는 App Store Connect 경고(ITMS-90897)를 피하려고 빼두었습니다.
   - 승인 전에도 실기기 개발 빌드에서는 같은 방법으로 시험해볼 수 있습니다(Development 권한).
3. 동작 방식
   - 플랜 저장 시 앞으로 7일간의 잠금 공부 플랜(최대 15개)을 DeviceActivity 일정으로 등록 → 앱이 꺼져 있어도 시작 시각에 잠기고 종료 시각에 풀립니다(`DOOOITActivityMonitor` 익스텐션).
   - 15분보다 짧은 플랜은 iOS 제한으로 예약이 안 되어, 앱이 켜져 있을 때 타이머 시작과 함께 잠급니다.
   - 타이머를 중간에 끝내면 잠금도 해제됩니다.
   - **실기기에서 꼭 확인할 것**: 잠금 상태에서 DOOOIT 자체는 열리는지. 만약 DOOOIT까지 잠기면 알려주세요(제외 목록 방식으로 바꿔야 합니다).

## 실행 방법

필요한 것: **Mac + Xcode 26 이상**, TestFlight 배포에는 **Apple Developer Program(유료) 가입**이 필요합니다.

1. `DOOOIT.xcodeproj`를 Xcode로 엽니다.
   (열리지 않으면 `brew install xcodegen` 후 이 폴더에서 `xcodegen generate`)
2. 프로젝트 → **DOOOIT** 타깃 → *Signing & Capabilities*
   - Team: 본인 개발자 계정 선택
   - Bundle Identifier: `com.bravekoon.dooit` → 본인만의 값으로 변경 (예: `com.내이름.dooit`)
3. **DOOOITWidgetsExtension**, **DOOOITActivityMonitor** 타깃도 같은 Team을 선택합니다. (Bundle ID는 `com.bravekoon.dooit.widgets`, `com.bravekoon.dooit.activitymonitor`)
4. 실제 iPhone을 연결해 실행합니다. (다이나믹 아일랜드, 문서 스캐너, Apple 로그인은 실기기에서 확인하는 것이 정확합니다)

## TestFlight 업로드

1. [App Store Connect](https://appstoreconnect.apple.com) → 나의 앱 → **+ 신규 앱** → 위에서 정한 Bundle ID로 생성
2. Xcode 상단 실행 대상을 **Any iOS Device (arm64)** 로 선택
3. **Product → Archive**
4. Organizer 창에서 **Distribute App → App Store Connect → Upload**
5. 처리 완료(보통 10~30분) 후 App Store Connect → **TestFlight** 탭에서 테스터 추가
   - 다시 올릴 때는 `CURRENT_PROJECT_VERSION`(빌드 번호)을 1씩 올려야 합니다.
   - 수출 규정(암호화) 질문은 `ITSAppUsesNonExemptEncryption = NO`로 미리 설정해 두었습니다.

## 알아두어야 할 제한 사항

- **빌드 미검증**: 이 프로젝트는 Mac이 아닌 환경에서 작성되어 Xcode로 컴파일해 보지 못했습니다. Swift 구문 검사만 통과한 상태라, 첫 빌드에서 타입 오류가 몇 개 나올 수 있습니다. 오류 메시지를 알려주시면 바로 고치겠습니다.
- **계정은 기기 안에만 저장**됩니다(Keychain). 서버가 없어서 기기 간 동기화가 되지 않고, 앱을 지우면 데이터도 지워집니다. 실제 서비스로 운영하려면 Firebase Auth / Supabase 같은 백엔드 연동이 필요합니다. Apple 로그인 토큰 철회(revoke)도 서버가 있어야 완전히 처리됩니다.
- **다이나믹 아일랜드 자동 시작**: iOS 정책상, 앱이 완전히 종료된 상태에서는 푸시 서버 없이 Live Activity를 새로 띄울 수 없습니다. 그래서
  - 앱이 실행 중이거나 최근에 열려 있었으면 → 다이나믹 아일랜드 카운트다운과 타이머 자동 시작이 동작하고,
  - 앱이 꺼져 있으면 → **N분 전 / 시작 시각에 알림**이 오며, 알림을 누르면 타이머가 자동으로 시작되고 다이나믹 아일랜드가 켜집니다.
  - 완전한 백그라운드 자동 시작을 원하면 APNs 푸시 서버(push-to-start)가 필요합니다.
- **모델 (DOOOIT 1·2)**: 작은 언어 모델이라 가끔 틀린 말을 할 수 있어요. 그래서 계산·수학 풀이·앱 기능은 규칙형 엔진이 맡고, 모델의 답은 검사를 거쳐요. 처음 다운로드할 때는 앱을 켜 둔 채로 기다려야 해요. 메모리가 적은 기기(6GB 미만)는 DOOOIT 1을 추천해요.
- **수학 자동 채점**은 정답이 입력되어 있거나 사진 속에 "정답/답" 표기가 있을 때 내 답과 비교하는 방식입니다. 문제를 직접 풀어서 채점하지는 않습니다(AI 연동 필요). 그 외에는 O/X 수동 채점을 사용합니다.
- **OCR 정확도**: 인쇄된 단어장은 잘 읽지만, 손글씨나 복잡한 배치는 틀릴 수 있어 저장 전 확인·수정 화면을 두었습니다. 수식은 일반 텍스트 수준으로만 인식됩니다.
